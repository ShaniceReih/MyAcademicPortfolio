# Portfolio Design Brief

## Goal
Create a clean, personal academic portfolio for Shanice Reih H. Tanque, a BS Computer Applications student at MSU-IIT majoring in Embedded Systems.

The site should feel like a genuine student-built technical portfolio, not a startup landing page or an AI-generated template.

## Visual direction
- Minimal and content-first
- Calm, professional, academic
- Strong typography and generous whitespace
- Simple navigation
- Flat layout with restrained borders
- Works especially well on mobile
- Use real project photos/screenshots where available

## Avoid
- Large marketing slogans
- Excessive cards
- Pills and decorative tags everywhere
- Gradients, glowing effects, glassmorphism
- Dashboard-style metrics
- Overly rounded components
- Generic AI-style copy
- Repeating section titles
- Dense walls of text

## Content hierarchy
1. Short introduction
2. About
3. Education
4. Selected work
5. Experience & leadership
6. Awards & recognition
7. Training & conferences
8. Contact

## Project presentation
Each project should be easy to scan:
- Project title
- One concise explanation
- Role or contribution when relevant
- Key tools/technologies
- Link to GitHub, Hackster, research page, or project page
- Real image/video when available

Do not turn every technology into a badge.

## Tone
Use straightforward first-person language. Avoid phrases that sound promotional or machine-generated. The portfolio should read like Shanice describing her own work.

## Important facts
- Degree: Bachelor of Science in Computer Applications
- Major: Embedded Systems
- IoT is an area of project experience, not part of the formal major.
- Keep the current resume link and project links working.
- Keep the current downloadable CV PDF.
- Preserve all factual project details already present in the site.

## Deployment
The site is plain static HTML/CSS and should remain easy to deploy to Vercel directly from GitHub.
