# DESIGN.md

## Design direction
A quiet, content-first academic portfolio.

The site should feel like a personal website made by a technically capable student, not a SaaS landing page, agency template, or AI-generated portfolio.

## Reference qualities
Use the following qualities as inspiration without copying another site:
- Strong reading hierarchy
- Simple navigation
- Generous whitespace
- Straightforward project descriptions
- Clear dates and roles
- Minimal visual decoration
- Real content carries the page

## Typography
Use one restrained sans-serif family consistently.

Preferred:
- IBM Plex Sans

Use:
- Regular body text
- Medium or semibold headings
- Modest heading sizes
- Comfortable line-height

Avoid:
- Oversized hero text
- Extreme font weights
- Strongly stylized display typography
- Too many type sizes

## Color
Mostly neutral:
- White background
- Near-black text
- Muted gray supporting text
- One restrained blue accent

Avoid:
- Gradients
- Glows
- Neon colors
- Large colored backgrounds
- Excessive dark sections

## Layout
Use a narrow-to-medium reading width.

Prefer:
- Simple sections
- Rows
- Dividers
- Two-column layouts only when they improve scanning
- Mobile-first readability

Avoid:
- Card grids everywhere
- Dashboard layouts
- Floating panels
- Bento grids
- Excessive boxed content

## Projects
Projects should read like documented work, not product cards.

Each project may include:
- Title
- Short description
- Role or contribution
- Key tools
- Relevant image
- Direct project link

Avoid:
- Technology pill clouds
- Metric chips
- Decorative labels
- Hover-heavy UI
- Repeating the same information in multiple forms

## Mobile
The mobile version is a priority.

Requirements:
- No duplicated headings
- No oversized body copy
- Comfortable margins
- Short line lengths
- No horizontal scrolling
- Images should not dominate the viewport
- Skills should remain easy to scan

## Interaction
Keep interactions basic:
- Normal links
- Subtle hover state
- Resume download/view
- No unnecessary animation

## Copy style
Prefer natural wording.

Example:
"I’m a BS Computer Applications student at MSU-IIT majoring in Embedded Systems."

Avoid:
"Building innovative systems where software meets hardware."

## Quality bar
A visitor should feel that the portfolio is:
- credible
- personal
- technically grounded
- easy to read
- intentionally simple
